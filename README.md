# WebSocket Chat (React + Node.js)

Клиент-серверное приложение для обмена сообщениями в режиме реального времени. 
Пользователи могут вводить свои имена, видеть список подключенных участников в сайдбаре и отправлять сообщения, которые мгновенно отображаются у всех участников чата.

## 🛠 Стек технологий

### Сервер (Backend)
- **Node.js** + **Express**
- **Socket.IO**
- **CORS**

### Клиент (Frontend)
- **React 19**
- **Vite** 
- **React Router DOM** 
- **Socket.IO Client**
- **CSS Modules**
